# Ninja Gaiden (NES) — Native Recompilation for Windows

Experience the original **Ninja Gaiden (1988)** on modern Windows PCs through a native recompilation project powered by [mstan's NESRecomp framework](https://github.com/mstan/nesrecomp).

This project aims to translate the original NES game's 6502 machine code into native C code, allowing it to run as a Windows x64 application while preserving the original gameplay experience.

## Features

- Native Windows x64 recompilation
- NESRecomp-based 6502 static recompilation
- Original NES graphics and gameplay
- Keyboard and controller support
- Windowed and fullscreen display modes
- ROM-selection launcher
- Original music and sound effects loaded from the user's ROM

*These are intended features; actual functionality depends on the current build and testing status.*

## Installation

1. Download `NinjaGaidenNESRecomp-Windows-x64.zip` from the release assets.
2. Extract the archive to a folder.
3. Launch `NinjaGaidenRecomp.exe`.
4. Select your legally obtained **Ninja Gaiden (USA).nes** ROM.
5. Start the game.

## ROM Requirements

**A compatible Ninja Gaiden (USA) NES ROM is required.**

No copyrighted game ROMs are included with this project.

Users must supply their own legally obtained copy of the game.

## Development Status
